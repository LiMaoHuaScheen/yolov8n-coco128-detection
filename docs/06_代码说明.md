## detect_coco128.py

### 模式总览

| 模式 | 功能 | 输出 |
|------|------|------|
| `prepare` | 切分数据集（修复官方泄漏） | data/coco128_split.yaml |
| `baseline` | 零样本评估 | results/baseline.json |
| `finetune` | 微调 lr=1e-3 | runs/yolov8n_ft_lr1e3/weights/best.pt |
| `scratch` | 从头训练 | runs/yolov8n_scratch/weights/best.pt |
| `evaluate` | 汇总三臂指标 | results/result_summary.json |

### 关键实现

#### 1) 数据切分（prepare）

~~~python
import random
random.seed(42)
# 官方 coco128.yaml 会把 train 混进 val（数据泄漏），
# 这里用固定种子切出三段零重叠的 80/20/28 划分
~~~

把 128 张图按固定种子洗牌，前 80 张做 train、20 张做 val、28 张做 test，三个集合**互不重叠**，写成新的 yaml。

#### 2) 评估（baseline / evaluate）

~~~python
def box_metrics(res):
    # ultralytics val() 返回 DetMetrics 对象，不是 res.results[0].metrics.box
    # 用 .box.map50 / .map / .mp / .mr 取指标
    return res.box.map50, res.box.map, res.box.mp, res.box.mr
~~~

`ultralytics` 新版 `val()` 直接返回 `DetMetrics`，`res.results[0].metrics.box` 这种旧写法会报错。`box_metrics()` 统一取 `map50 / map / mp / mr`（对应 mAP50、mAP50-95、Precision、Recall）。

#### 3) 训练（finetune / scratch）

~~~python
from ultralytics import YOLO

def train(model_path, data_yaml, out_name, pretrained, lr0):
    model = YOLO(model_path)
    results = model.train(
        data=data_yaml, epochs=50, patience=12, imgsz=640, batch=8,
        project="runs", name=out_name, lr0=lr0,
    )
    return results
~~~

微调用 `pretrained=True`（加载官方 yolov8n.pt），从头用 `pretrained=False` + `model="yolov8n.yaml"`（随机初始化）。

> 注意：`yolov8n.yaml` 不在独立文件里，它在 `ultralytics/cfg/models/v8/yolov8.yaml`，直接写 `YOLO("yolov8n.yaml")` 会报文件不存在。
