## 核心数字

| 指标 | 零样本 | 微调 | 从头 |
|------|--------|------|------|
| mAP50 | **0.6365** | 0.6296 | 0.0006 |
| mAP50-95 | 0.4552 | 0.4554 | 0.0002 |

**一句话结论**：小数据检测里，预训练权重是唯一信号；微调无增益，从头训练失败。

## 与第一步的对照（数据规模决定论）

| | 第一步：图像分类 | 第二步：目标检测 |
|------|----------------|----------------|
| 数据量 | 50k 训练图 | 80 训练图 |
| 从头训练 | 71.48% | mAP50 0.0006 |
| 微调 | 82.04%（+10.56pp） | 0.6296（-0.7pp） |

检测需要比分类多几个量级的数据。这是本步最有价值的一课。
