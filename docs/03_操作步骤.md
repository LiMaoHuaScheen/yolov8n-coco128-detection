# 03 操作步骤

## 从零复现（约 15 分钟）

### 第 1 步：安装依赖

~~~bash
pip install -r requirements.txt
~~~

### 第 2 步：下载数据

~~~bash
python download_data.py
~~~

### 第 3 步：切分（修复泄漏）

~~~bash
python code/detect_coco128.py prepare
~~~

> 输出：train 80 / val 20 / test 28，三段零重叠，写入 coco128_split.yaml

### 第 4 步：零样本基线

~~~bash
python code/detect_coco128.py baseline
~~~

> 输出：results/baseline.json（mAP50 0.6365）

### 第 5 步：微调（lr=1e-3）

~~~bash
python code/detect_coco128.py finetune
~~~

> 50 epoch，patience=12，早停于约 13 epoch。输出 runs/yolov8n_ft_lr1e3/weights/best.pt

### 第 6 步：从头训练（可选）

~~~bash
python code/detect_coco128.py scratch
~~~

> 较慢（约 123 秒），输出 runs/yolov8n_scratch/weights/best.pt

### 第 7 步：汇总评估 + 绘图

~~~bash
python code/detect_coco128.py evaluate
python code/plot_detect.py
~~~

> 输出：results/result_summary.json + figures/ 两张图

## 训练时间参考（RTX 5060 Laptop 8GB）

| 阶段 | 耗时 |
|------|------|
| 零样本评估（28 张） | ~5 秒 |
| 微调（13 epoch） | ~36 秒 |
| 从头训练（12 epoch） | ~123 秒 |
| 总实验 | ~5 分钟 |
