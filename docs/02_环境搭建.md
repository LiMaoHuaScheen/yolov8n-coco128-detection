## 安装命令

~~~bash
pip install torch==2.11.0+cu128 torchvision==0.26.0+cu128 --index-url https://download.pytorch.org/whl/cu128
pip install ultralytics --index-url https://mirrors.aliyun.com/pypi/simple/
~~~

> 若 PyPI 直连慢，用阿里云镜像：`--index-url https://mirrors.aliyun.com/pypi/simple/`

## 数据集与权重获取

GitHub releases 上的 ultralytics assets 有两个 tag：

- `v0.0.0`：数据集（coco128_with_yaml.zip）
- `v8.2.0`：模型权重（yolov8n.pt）

~~~bash
# 用 gh release download（需要 GitHub token，比直连 HTTPS 更稳）
gh release download v0.0.0 -R ultralytics/assets -p coco128_with_yaml.zip
gh release download v8.2.0 -R ultralytics/assets -p yolov8n.pt
~~~

## 踩坑记录

1. **VOC2007 镜像不可达**：aliyun/tencent/ox.ac.uk 全部 404 或超时，改用 COCO128。
2. **官方 coco128.yaml 数据泄漏**：train 和 val 指向同一批图，必须手动切分。
3. **GitHub 直连超时**：plain HTTPS 到 github.com 超时，用 `gh release download`（走认证 token）可通。
4. **ComfyUI 占显存**：8GB 卡被 ComfyUI（4.5GB）+ 游戏（7GB）占用时训练 OOM，需先停掉占用进程。
